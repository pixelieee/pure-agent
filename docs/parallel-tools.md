# 有界并行工具执行

`createAgent` 和 `createDeveloperAgent` 支持 `maxToolConcurrency`，默认 **1**，保持顺序执行兼容。显式传入大于 1 的正安全整数才启用并行。CLI 暂无配置入口。

工具必须声明 `parallelSafe: true` 才能与相邻的同类调用并行。省略或 `false` 是串行屏障：等待之前的调用和观察回调结束，独占执行，然后才启动后续调用。内建 `read/find/ls/grep` 已声明安全；`write/edit`、进程工具以及未声明的自定义/Web/MCP 工具保持串行。未知工具同样作为屏障并返回错误。不得仅根据名称推断第三方工具安全。

`parallelSafe` 是宿主关于实现、共享状态及授权回调并发安全的承诺，不是模型参数，也不是权限许可。注册时复制并验证该字段；非 boolean 拒绝。所有调用仍经过 Schema 校验、业务校验和原有宿主授权。不改变路径边界或授予额外权限。外部进程仍可能改变文件，本功能不提供跨进程事务或锁。

相邻安全调用以配置上限运行，空出的槽位可接续该组剩余调用。结束事件按实际结算顺序发出，本批全部结算后才将结果写入历史，始终与原始调用一一对应、顺序不变。运行中的 `messages` 不代表已完成的快照，不能用结束事件到达时读取历史推断单次结果；使用事件自身的 `result`。观察回调串行隔离，失败不触发重试。`tool_start` 表示准备执行，不保证工具已进入：观察回调期间取消仍阻止执行；`tool_end` 也可能报告校验失败或未执行的取消结果。

取消后不启动待执行工具；已启动的全部调用必须结算，不能把仍可能写入的工具留在后台。工具若在取消后正常完成，保留它的真实结果；协作取消则保留实际错误。未启动调用返回 `Cancelled before execution`。不提供强制终止任意回调；不协作或不返回的工具、授权/观察回调可能阻塞结束。没有自动工具重试，失败后副作用可能已发生，调用方应先检查实际状态。

## 参考与验证边界

源码阅读：[Pi e8504df 的 agent-loop.ts](https://github.com/earendil-works/pi/blob/e8504dfab5fb3aa023322a7e89b43c0eb49e6120/packages/agent/src/agent-loop.ts)，文件 blob `cfc9401e5581847f6d5a9bb1815ab0f0e663f2e5`。该版本支持显式串行覆盖和 `Promise.all` 并行，结果消息按调用顺序组织，工具执行没有自动重试。本实现采用有界、显式安全声明和局部串行屏障，未复制 Pi 源码，也未声称完全对齐其协议。

`test/tool-execution.test.ts` 直接调用生产工具执行边界，以真实临时文件及受控同步验证并发上限、乱序结束/有序结果、串行屏障、默认顺序、取消等待、错误隔离及真实内建文件工具。它不伪造模型或 HTTP 响应。组件检查不等于模型循环 E2E；真实 API 集成仍等待安全凭据导入与独立验收。Hooks、恢复框架、自动重试与 CLI 配置不在此变更中。

工具前后控制接口及其并发责任见 [工具生命周期 hooks](tool-hooks.md)。`parallelSafe` 的宿主承诺也覆盖这些 hooks。
